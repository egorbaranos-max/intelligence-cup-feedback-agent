# Что исправлено и что остается команде

Это состояние прототипа, а не заключение о готовности к промышленной работе. 🔴 обозначает незакрытый вопрос, для которого нужны люди, доступы или реальные данные. Для первого этапа отправляется ссылка на репозиторий.

| Ошибка или ограничение | Что исправлено или подготовлено | Действия команды |
|---|---|---|
| Посторонний не видит приватный GitHub | Документы и код собраны в одном репозитории; порядок проверки доступа описан | 🔴 Владелец согласует доступ экспертов: приглашения либо разрешенная публикация. Проверить ссылку из аккаунта эксперта, а при публикации — без авторизации. |
| Модель создавала ложные пожелания, пропускала реальные и смешивала разные темы | **Смысловая ошибка не устранена.** На 48 примерах новая 4B выдала 4 карточки: 1 согласуется с исходниками при AI-разборе, 3 смешаны. Программные проверки прошли 47 ответов; в ручной очереди 22 обращения. Все результаты сохранены | 🔴 Проверить цитаты в контексте и принадлежность каждого источника теме. Нужны дальнейшая разработка и новый человеческий экзамен; автоматическую публикацию рабочих задач пока не включать. |
| Модель переписывала цитаты и нарушала формат ответа | Точные фрагменты источника, ограничения полей и категорий, один повторный запрос при ошибке; обе попытки сохранены | Проверять смысл цитаты вместе с полным обращением. Правильная структура ответа сама по себе не доказывает правильное решение. |
| Команды внутри обращения могли превратиться в ложный спрос | Ограниченный защитный фильтр удерживает подозрительный источник целиком для человека | 🔴 Разбирать очередь и измерять пропуски/лишние задержки. Фильтр не закрывает все атаки; обычный запрос о редакторе промптов тоже может попасть человеку. |
| Первые пять кандидатов не покрывали все темы | Темы сравниваются пакетами: весь список до 25, неоднозначность и превышение лимита требуют разбора | 🔴 Назначить проверяющего и измерять время на ручную очередь. Для большего каталога отдельно спроектировать и проверить поиск. |
| Нельзя было связать общий PASS с конкретными файлами | Офлайн-аудит сохраняет Git-версию, если она есть, и хеши исходников; изменения во время проверки дают отказ | Повторить аудит финального ZIP. Читать `skipped`: пропущенная проверка не выполнена. Аудит не измеряет точность модели. |
| Нет подключений к настоящей поддержке и внутренней модели | Описаны контракты, локальные файлы и имитатор получателя | 🔴 Для пилота нужны компания, API, права, реальные связи эпизодов и тестовый получатель. Полный путь для звонков/изображений пока не реализован. Для первого этапа эти доступы не обязательны. |
| Субагент подготовил противоречивые проверочные ответы | Найдены 9 несогласованных статусов и неоднозначные цитатные метки. Составлен отдельный [список предлагаемых исправлений](../experiments/holdout_v2/annotation-fixes-proposed.md); первоначальная оценка сохранена | 🔴 Люди должны согласовать правильные ответы. Предложения ИИ еще не являются эталоном; нельзя незаметно переписать проверку под результат модели. |
| Дообучение весов не выполнено; человеческого эталона пока нет | Есть форма разметки, сверка разногласий и экспорт проверенных примеров | 🔴 Два человека независимо размечают разрешенные данные, третий разрешает споры. Сохранить отдельный экзамен; затем обучать и сравнивать версии. |
| Денежный эффект не измерен; подготовлен условный расчет | Проверяемая модель сценария: 2760 часов; 2,986 млн ₽ — условный предел затрат, не прибыль | 🔴 Компания подтверждает трудозатраты, денежные выгоды и все расходы. Высвобожденные часы не считать автоматическим уменьшением зарплат. |
| Итоговую сдачу должны принять участники | Основной ответ, отдельные показатели, слайды и инструкции готовы как комплект материалов | 🔴 Согласовать состав/название команды и допущения, самим заполнить оценки использования ИИ при выборе этой необязательной таблицы. Проверить финальные файлы и лимит текста после правок, затем отправить доступную ссылку. |

В подсчете повторов связанные обращения относятся к одному эпизоду; неизвестные идентификаторы не превращаются в новых клиентов. Подробности: [что за проект](project-in-plain-russian.md), [как проверить результат](../docs/how-to-check-our-work.md), [подключения](../docs/connection-plan.md), [разметка и дообучение](../docs/training.md).

Для первого этапа основная работа команды — прочитать и принять конкурсные материалы, повторить проверку и обеспечить доступ по ссылке. Настоящее внедрение потребует больше усилий: разметки обращений, корпоративных подключений, проверки прав и замеров всех трудозатрат. Большая очередь ручного разбора может съесть ожидаемую экономию; это один из главных вопросов пилота.
