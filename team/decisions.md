# Что изменилось после независимой критики

Этот документ нужен команде для подготовки к защите. Он не расширяет конкурсный ответ: основной документ не ссылается на него за дополнительными ответами.

| Замечание к первой версии | Что исправили |
|---|---|
| Один результат `topic_match` относился сразу к нескольким намерениям, а гипотезу нельзя было выразить в JSON. | Промпт извлекает массив `intents` с полями `kind`, `origin` и ссылками на подтверждения. Каждое намерение сопоставляется отдельно. Новая тема создается только при отсутствии результатов `same` и `unclear`. |
| Выборка отдельных обращений не позволяла установить, повторяется ли тема. | Для эталона предусмотрен полный поток обращений за выбранные периоды по продуктам, включая предысторию и последующее наблюдение. |
| Отбор только пяти тем мог снижать покрытие. | В очередь попадают все темы, прошедшие правила. Пять главных тем выделяются только в дайджесте. |
| Прирост на 20 п.п. недостижим, если исходное покрытие уже высокое. | Вариант критерия выбирается после измерения исходного уровня, до получения результатов рабочего пилота. |
| Было неясно, какой показатель должен пройти порог: точечная оценка или доверительная граница. | Пороги заданы для нижних 95% доверительных границ точности и полноты. Объем независимой тестовой выборки должен позволять их оценить. |
| Коэффициент `α`, примененный к чистой экономии часов, смешивал деньги и стоимость новой работы. | Денежная выгода `b` задается независимо на основе реестра платежей. Высвобожденное время учитывается отдельно. Все денежные расходы проекта входят в единый дисконтированный бюджет. |
| Постепенный выход на полный эффект уменьшал в расчете и фиксированный объем новой работы. | Коэффициент освоения применяется только к доходу. Для часов работы и платежей используются отдельные календари. |
| Право сервиса прочитать источник ошибочно приравнивалось к праву переслать цитату владельцу продукта. | Проверяются права каждого получателя на все передаваемое содержание. Данные разделяются по доступности, а уведомление содержит только ссылку. |
| После удаления цитаты счетчик и карточка могли остаться неверными. | Анализ аннулируется, счетчики пересчитываются, карточка обновляется или отзывается. Старая версия защищена от повторной публикации. |
| Оценка в 1,2 вызова Qwen не была связана с этапами обработки. | Число вызовов определяется формулой `N×(1+f×m)×(1+ρ)`. Кандидаты сравниваются одним пакетом. |
| Проверка сложных случаев требовала найти ошибку даже в исправной системе. | Для тестов заданы ожидаемые результаты. Заведомо неверные входные данные позволяют проверить, способны ли тесты обнаружить соответствующую ошибку. |
| В конце документа о метриках во второй версии все еще требовался прирост, даже если исходное покрытие высокое. | Условие окончательной приемки приведено в соответствие с вариантом критерия, выбранным до пилота. |

Решение проверили по двум независимым направлениям, затем повторно рассмотрели исправленную версию. Финансовые значения пересчитали независимо. Закрытые замечания относятся к проектной логике; они не подтверждают успешность реального пилота. Неизвестные параметры компании по-прежнему обозначены как неизвестные.

## Третья итерация

После просьбы продолжить работу проверка затронула не только описание, но и поведение демонстратора и калькуляторов.

| Найденная проблема | Что изменили и проверили |
|---|---|
| Источник с неустановленной связью считался независимым эпизодом. | Такие контакты учитываются отдельно. Код проверяет порог 3/2: три источника, относящиеся к двум эпизодам, не позволяют опубликовать карточку. |
| При отсутствии роли автора система считала его пользователем. | По умолчанию задано `unknown`. Для `user_explicit` требуется подтвержденное `speaker=user`; гипотезы не включаются в `wish-topic`. |
| Скрытые эпизоды и заголовки влияли на доступную получателю карточку. | Права ограничивают данные до расчета счетчиков и порога. Общий текст, составленный по всем источникам, не копируется в карточку с ограниченным доступом. |
| После выхода эпизодов за пределы 30 дней порог уже не выполнялся, но доставленная карточка оставалась актуальной. | Изменение времени запускает пересчет окна и отзыв устаревшего содержимого у имитатора получателя. |
| Отсутствие темы в последние 30 дней ошибочно подтверждало ее новизну. | Новизна проверяется по историческому реестру и независимому аудиту. Темы с неизвестным прошлым учитываются отдельной группой. |
| Финансовый расчет требовал проверки `NaN` и `Infinity`; неуказанные расходы могли быть приняты за нулевые. | Добавлена строгая проверка финансовых входных данных. Расходы нужно задавать явно. NPV, допустимый остаток первоначального бюджета `I0` и срок окупаемости по концам лет зависят от введенных допущений. |
| Формула Coverage7 была только в тексте. | Создан отдельный калькулятор. Он учитывает полный срок наблюдения, пропуски, область доступности, группы `known`/`fallback` и пустой знаменатель. Доверительные интервалы без данных не рассчитываются. |

В конце третьей итерации локально выполнены 42 теста программных контрактов, 16 финансовых тестов и 18 тестов Coverage7. Они проверяют программу на синтетических случаях. Реальные модели, корпоративный эталон и окупаемость не испытывались.
