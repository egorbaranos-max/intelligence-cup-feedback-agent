# Изменения после независимой критики

Материал внутренней подготовки команды. Он не является расширяющим приложением к конкурсному ответу и не используется основным документом как источник дополнительных ответов.

| Замечание первой версии | Принятое исправление |
|---|---|
| Один topic_match на несколько намерений; hypothesis не выражается в JSON | Extraction-only массив intents с kind/origin/evidence; сопоставление отдельно на одно намерение; новая тема только без same и unclear |
| Выборка отдельных тикетов не наблюдает повторяемость тем | Отдельный сплошной эталон продуктовых окон с предысторией и последующим наблюдением |
| Top-5 может ограничить покрытие | Все прошедшие правила темы в очереди; top-5 только подсветка дайджеста |
| +20 п.п. недостижимы при высоком baseline | Ветка критерия выбирается после baseline, но до результатов живого пилота |
| Неясно, точка или интервал проходит gate | Заданы нижние 95% границы precision/recall; объем независимого теста должен быть достаточным |
| α от чистых часов смешивает cash и стоимость нового труда | Cash b — независимый сценарный вход реестра платежей; capacity отдельно; все денежные расходы проекта в едином PV бюджете |
| Ramp уменьшает фиксированную новую работу | Ramp применяется только к доходу; часы/платежи имеют отдельный календарь |
| Права сервисного чтения не дают право пересылки цитат PM | Права каждого получателя на все раскрываемое содержание, отдельные области видимости, уведомление только ссылкой |
| Удаление цитаты оставляет неверную частоту/карточку | Инвалидация анализа, пересчет и обновление/отзыв карточки, защита от переиздания старой версии |
| 1,2 вызова Qwen не связано с этапами | Формула N×(1+f×m)×(1+ρ), пакетное сравнение кандидатов |
| Challenge-тест должен сначала найти реальную ошибку исправной системы | Ожидаемые результаты и заведомо неправильные fixtures проверяют чувствительность тестов |
| Во второй версии финал метрик требовал прирост даже в ветке высокого baseline | Финальная приемка синхронизирована с заранее выбранной веткой критерия |

Проведены два независимых направления критики и повторный проход исправленной версии. Числа финансов пересчитаны независимо. Закрытие замечаний относится к проектной логике, а не к успешному реальному пилоту. Неизвестные параметры компании сохраняются неизвестными.
