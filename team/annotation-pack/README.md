# Пакет независимой разметки

Откройте `index.html` из скачанного репозитория обычным браузером на компьютере. Это локальная форма; GitHub показывает ее код, а не запущенное приложение. Интернет, сервер, ключ API и подписка для формы не нужны.

Внутри 35 уже использованных отладочных обращений: семь из задания и 28 вымышленных. Ответы не заполнены. Эти обращения не являются независимым тестом текущей версии.

Каждый участник работает в своей копии и регулярно скачивает JSON кнопкой формы. До согласования не смотрите разметку второго участника или ответы модели. Локального автоматического сохранения нет: закрытие вкладки без выгрузки потеряет изменения.

Полная процедура, ограничения и команды экспорта — в [инструкции по обучению](../../docs/training.md).
