# Человеческая проверка 48 контрольных примеров

Откройте `index.html` из скачанной локальной копии. Это пустая форма на тех же 48 текстах, которые использованы в итоговом сравнении. Ответы Qwen и предварительные ответы ИИ в форму не подставлены. Она ничего не отправляет в сеть.

Два участника независимо отмечают намерения и точные цитаты, каждый сохраняет свой файл. Третий разбирает разногласия по [процедуре](../../docs/training.md). По возможности сначала заполните форму, затем читайте ответы модели и автоматические оценки. Если вы уже видели их, сообщите об этом при обсуждении результатов: оценка может быть пристрастной.

Особенно внимательно проверьте отрицания, благодарности, пожелания с несколькими смыслами и русско-английские фразы. В предварительной разметке ИИ обнаружены ограничения; она не должна становиться правильным ответом только потому, что лежит в репозитории.

Этот набор уже использован для испытания текущей версии. Его человеческая проверка поможет разобраться в ошибках оценки и подготовить данные, но не сделает набор новым независимым экзаменом для последующих изменений. Для следующего экзамена нужны другие примеры.

Форма фиксирует заявленное имя проверяющего и его подтверждение работы. Она не проверяет личность человека и не гарантирует истинность ответа. Веса модели здесь не обучаются.
