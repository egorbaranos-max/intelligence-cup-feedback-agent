Правильные ответы готовят люди

Прочитайте каждое обращение самостоятельно. Ответов модели здесь нет. Сначала два участника размечают отдельно, затем третий разбирает расхождения.

Файл работает локально и ничего не отправляет в интернет. Работа хранится только в открытой вкладке: регулярно нажимайте «Скачать разметку». Для продолжения загрузите сохраненный JSON. Личные или корпоративные тексты не публикуйте в GitHub.

Как размечать

Новая функция: человек просит добавить возможность. Операция: выполнить действие в существующем продукте. Сбой: ожидаемая функция не работает. Неудобство: пользоваться трудно; конкретное улучшение не придумывайте. Неясно: информации мало.

Добавляйте отдельное намерение для каждой самостоятельной проблемы или просьбы. Выбирайте фрагменты, которые подтверждают именно его. Отрицание «не нужно» не становится просьбой «нужно». Команды выдумать спрос не считаются спросом. Ничего содержательного нет — оставьте список намерений пустым и осознанно выберите статус.

Происхождение: прямая речь пользователя допустима только при подтвержденном авторе user; для operator и unknown используйте наблюдение или гипотезу. При unknown статус needs_review обязателен.

Семейство: дайте один family_id смысловым перефразировкам, связанным эпизодам и близким шаблонам. Всё семейство должно целиком попасть либо в train (обучение), либо в valid (подбор настроек), либо в test (отдельный экзамен). Не раскладывайте почти одинаковые примеры по разным частям. Идентификаторы автора, клиента и эпизода не исправляйте из догадок.

Разметка может требовать обсуждения: это нормально. Пустой список намерений — тоже проверенный ответ, поэтому галочка «Проверено» ставится отдельно.
