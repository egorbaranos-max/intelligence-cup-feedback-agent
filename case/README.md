# Условие кейса

- `условие.md` — структурированная расшифровка условия Intelligence Cup 2026 («Газпром нефть», ИИ-агент для ретрансляции обращений в поддержку). Единственный источник истины для требований, ограничений и критериев.
- PDF организаторов положи сюда как `Кейс_ИИ-агент.pdf`. Он не коммитится (`case/*.pdf` в `.gitignore`), чтобы не публиковать материалы чемпионата от своего имени.
