# Использование ИИ при решении кейса

В таблице указано, какую работу выполнил ИИ при подготовке решения. Оценки оставлены пустыми: команда заполнит их после проверки материалов. Проведены локальные прогоны Qwen3-4B и Qwen3-8B на синтетических примерах. Мы не проводили интервью с сотрудниками и не получали доступ к корпоративным данным; качество в контуре заказчика пока не проверено.

| Шаг | Для чего использовали ИИ | Оценка команды от 1 до 5 | Что вошло в решение |
|---|---|---|---|
| 1 | Прочитать PDF, извлечь требования, визуально проверить страницы | | Ограничения контура, 40 менеджеров, год истории, формат и объем сдачи |
| 2 | Бизнес анализ и поиск идей по BMad, 120 идей и 12 методов | | Раздельный учет пожеланий и проблем, карточка с цитатами, состав пилота, сравнение с BI |
| 3 | Отдельный агент проверил архитектуру, нагрузку, права и обработку текста, речи и изображений | | Три приложения для пилота, пять логических сервисов, проверка версий и цитат, контроль доступа и доставки |
| 4 | BMad Deep Recon и веб исследование первичных источников | | Проверенный макроконтекст ЦБ, принципы защиты OWASP и ограничения выводов |
| 5 | Отдельный агент разработал метрики, проверку истории обращений, план измерения эффекта и финансовую модель | | Coverage7, расчет при неполных данных, раздельный учет часов и денег, предел вложений |
| 6 | Два агента искали слабые места по BMad Advanced Elicitation, включая разбор возможных провалов и возражений жюри | | Исправлены формат нескольких намерений, учет пропущенных тем, лимит дайджеста, денежная модель, права и удаление |
| 7 | Агенты повторно проверили новую версию и независимо пересчитали финансовую модель в Python | | Уточнены приемка при высоком исходном покрытии, создание темы при неопределенности и финансовые сценарии |
| 8 | Написание локального демонстратора и тестов программных контрактов | | Проверка доказательств, ACL, эпизодов, идемпотентности и удаления; эти тесты сами по себе не подтверждают качество Qwen |
| 9 | Подготовка документов, слайдов, README и репозитория | | Комплект для сдачи, редактируемые исходники и материалы подготовки команды |
| 10 | Третья независимая критика, исполнение контрпримеров и доработка кода | | Исправлены неизвестные связи, авторство, область прав и старение окна; добавлены калькуляторы, отдельные когорты KPI и сценарий защиты |
| 11 | Отдельные агенты отредактировали язык, после чего обновлены документы и слайды | | Убраны тяжеловесные фразы и лишний жаргон. Допущения и ограничения сохранены |
| 12 | Реальные локальные прогоны Qwen3-4B и Qwen3-8B | | Сохранены исходные ответы, ошибки и неуспешные попытки. Результаты относятся к синтетическим примерам и не доказывают качество на данных заказчика |
| 13 | Независимые агенты составили синтетические примеры и предварительные ответы | | Разметка создана ИИ и требует проверки людьми. Отдельный набор из 48 записей зафиксирован с хешами; испытание моделей на нем еще не выполнено |
| 14 | Поштучный разбор ответов агентами и исправление обработки ошибок | | Добавлены проверяемые ссылки на фрагменты исходного текста и ограниченное число повторных запросов при ошибках. Сбои сохранены для проверки |
| 15 | Создание инструмента для разметки двумя людьми, согласования третьим участником и экспорта учебных данных | | Реализованы проверки источников, цитат, полноты и разделения выборок. Человеческая разметка и дообучение весов моделей не выполнены |

Участники поставили задачу, передали условие, указали состав команды и попросили создать репозиторий GitHub. Команде предстоит принять окончательное решение, заполнить оценки и проверить применимость предложения к данным заказчика. Для первого этапа требуется ссылка на репозиторий; устная защита на этом этапе не предусмотрена. Подготовка к возможной защите в финале потребуется позднее.

В условии заданы 40 менеджеров и хранение обращений за год. Остальные числа о производительности, времени и денежных потоках использованы для расчетных сценариев. Вымышленные примеры отмечены отдельно. Независимая критика помогла исправить проект, а его пользу еще предстоит проверить в пилоте.
